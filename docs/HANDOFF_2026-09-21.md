## 0. Orientation in one paragraph

The question is whether public awareness of police violence changes what New
Yorkers ask EMS for. Outcome: mental-health / EDP call share and count at
community-district × day level, 59 districts. Treatment: a composite national
attention index built from Wikipedia pageviews on a basket of police-violence
articles plus US Google Trends. Design: stacked episode event study with
episode-level randomization inference under a confirmation freeze — 2017–2020
explorable ("discovery"), 2015-07→2016-12 and 2021→2024 sealed ("confirmation";
strata C1 clean of B-HEARD and C2 exposed to it). The freeze was lifted at
`4e3dce1` on 2026-09-20 after every stratum's null was certified at 1,000
simulations; one sealed script (`30_confirmatory_run.py`) ran once and one
mechanical reader (`34_confirmatory_reading.py`) read it once. **The confirmatory
result is the pre-specified null in both strata** (PRE_ANALYSIS_NOTE 9.4 row 5,
read by addendum §19 rule 2). The pre-registration is `CONFIRMATION_PLAN.md`
(frozen text + addendum §1–§30) and `PRE_ANALYSIS_NOTE.md`; the discovery result is
a bounded null too. The manuscript (`docs/PAPER.md`) is complete and has passed a
full adversarial audit (CP3); the one open item is the author's editorial pass.

## 4. What I got wrong, so you do not repeat it

- **The paper's account of the record was softer than the record** (CP3's five
  surviving findings): F1/F2 called "metadata reads" and F3 a "coverage read"
  when all three read outcome values; "never used for any specification
  choice" (F2's EDPM decision, F4's weights); "no number from them was kept"
  (the F4 weights are in the B-HEARD exposure covariate); "before any
  confirmation-period outcome was seen" (F1–F3 precede the commitments); and a
  closing claim that the compositional damping biases toward the null when it
  runs in the predicted direction. Lesson: when the paper paraphrases the
  record, quote the record's own nouns; the suite now holds the corrected
  wording (P59–P63).
- **A generator omission hid nine sealed cells**: Table 8b.3 looped over C1 and
  C2 only, so the pooled falsification and diagnostic rows reached no exhibit.
  Every table that says "per stratum" must loop over every stratum in the file.
- **A Methods definition drifted from the code**: "divided by all dispatches"
  omitted the disposition filter; the episode label was described as one
  registry death when Table 1 carries the 60-day candidates; the freeze
  architecture was described pre-D8. Read the generator and the docstring
  before writing the sentence, not after.
- **A table label that begins with a numeral is a value to the exhibit check**
  ("28-day post window"), and a mechanical rename of it spliced into prose
  ("post window 60 dayss") in three places. Rename by whole-cell match only.
- **A citation marker inserted into a claim's anchor sentence breaks the claim**
  (C161). Grep the register for the sentence before adding a reference.
- **A Monitor filter that embeds python in a single-quoted shell string prints
  nothing** (the escaped quotes become a syntax error on stderr); the watch
  expired with "no events" while the workflow was working. Keep monitor scripts
  to grep and cut.
- **A workflow prompt written before the run finished went stale** ("resumed
  once"); re-read every factual statement in a prompt before launching it.
- Carried from 2026-09-20 (still binding): the container suspends minutes after
  the session goes idle; check runs by PID; stamp sidecars after every edit to
  a hashed source; never grep the script's own name from a command whose text
  contains it (match `[s]pawn_main`); always run the defeat attempt.

## 6. Conventions that are not obvious

- Every long job runs through a runner in `ops/` with a PID file and a state
  file under `ops/state/` (gitignored); poll by PID, never `pgrep -f`; a second
  real start of 30 needs `PHASE_I_RESUME_REASON`, which is recorded.
- Every change passes the gate twice; every new check or token gets a defeat
  attempt; the baseline is refreshed in the commit that adds a check.
- Register CSVs are CRLF and are written through the csv module (templates may
  contain a wrapped newline inside the quoted field; that is the convention).
- Table labels never begin with a numeral; a claim's anchor must be re-checked
  whenever the sentence it sits in is edited, including a reference marker.
- Generated claims are replaced wholesale when the generator changes (rows whose
  note names `ops/phase_i_tables.py`), never edited by hand.
- `PYTHONHASHSEED=0` and single-threaded BLAS for anything whose bytes matter;
  the runners export them; the gate is run the same way.
- The capsule, the graph export and `vault/` are updated with every commit that
  changes state; the Mac copies are reconciled by import.
