## 0. Orientation in one paragraph

The question is whether public awareness of police violence changes what New
Yorkers ask EMS for. Outcome: mental-health / EDP call share and count at
community-district × day level, 59 districts. Treatment: a composite attention
index built from Wikipedia pageviews on a basket of police-violence articles plus
US Google Trends. Design: stacked episode event study with episode-level
randomization inference under a confirmation freeze — 2017–2020 explorable
("discovery"), 2015-07→2016-12 and 2021→2024 sealed ("confirmation"; strata C1
clean of B-HEARD and C2 exposed to it). The freeze was lifted at `4e3dce1` on
2026-09-20 after every stratum's null was certified at 1,000 simulations; one
sealed script (`30_confirmatory_run.py`) ran once and one mechanical reader
(`34_confirmatory_reading.py`) read it once. **The confirmatory result is the
pre-specified null in both strata** (PRE_ANALYSIS_NOTE 9.4 row 5, read by
addendum §19 rule 2). The pre-registration is `CONFIRMATION_PLAN.md` (frozen text
+ addendum §1–§30) and `PRE_ANALYSIS_NOTE.md`; the discovery result is a bounded
null too.

## 4. What I got wrong this session, so you do not repeat it

- **A table label that begins with a numeral is a value to the exhibit check.**
  "28-day post window" in the sensitivity tables produced 48 uncovered cells.
  Labels now read "post window 28 days"; the rule is in vault `Decisions`.
- **A citation marker inserted into a claim's anchor sentence breaks the
  claim.** Adding ¹² to "precinct-level report (31 precincts" made C161 report a
  mismatch. When you add a reference marker, grep the register for the sentence.
- **The abstract's first draft was structured and 266 words** against the plan's
  unstructured ≤250 with named dataset, place and period. Read PAPER_PLAN's
  section spec before drafting a section, not after.
- **A workflow prompt written before the run finished went stale**: the CP3
  script said the run was "resumed once" when it had seven starts. Re-read every
  factual statement in a prompt against the artifacts before launching it.
- **Three workers for speed cost a second OOM kill** on the pooled stratum's
  60-day cells. Two workers fit the cgroup; the pooled cells are the memory peak.

  defeat attempt on a new check.

## 6. Conventions that are not obvious

- Every long job runs through a runner in `ops/` with a PID file and a state
  file under `ops/state/` (gitignored); poll by PID, never `pgrep -f`; a second
  real start of 30 needs `PHASE_I_RESUME_REASON`, which is recorded.
- Every change passes the gate twice; every new check gets a defeat attempt; the
  baseline is refreshed in the commit that adds the check.
- Register CSVs are CRLF and are written through the csv module (templates may
  contain a wrapped newline inside the quoted field; that is the convention).
- Table labels never begin with a numeral; a claim's anchor must be re-checked
  whenever the sentence it sits in is edited, including a reference marker.
- `PYTHONHASHSEED=0` and single-threaded BLAS for anything whose bytes matter;
  the runners export them; the gate is run the same way.
- The capsule, the graph export and `vault/` are updated with every commit that
  changes state; the Mac copies are reconciled by import.
