## 0. Orientation in one paragraph

The question is whether public awareness of police violence changes what New
Yorkers ask EMS for. Outcome: mental-health / EDP call share at community-district
× day level, 59 districts. Treatment: a composite attention index built from
Wikipedia pageviews on a basket of police-violence articles plus US Google Trends.
Design: stacked episode event study with episode-level randomization inference,
under a **confirmation freeze** — 2017–2020 is explorable ("discovery"), 2015-07→
2016-12 and 2021→2024 are sealed ("confirmation"; strata C1 clean of B-HEARD and
C2 exposed to it), `FREEZE_ACTIVE = True` enforces it through
`freeze_guard.select_sample()`, and one sealed script (`30_confirmatory_run.py`)
with one mechanical reader (`34_confirmatory_reading.py`) runs once after the flag
flips. The pre-registration is `CONFIRMATION_PLAN.md` (frozen text + addendum §1–§30)
and `PRE_ANALYSIS_NOTE.md`; the discovery result is a bounded null.

- **Assumed C2's 1,000-sim run had started.** `calib1000.sh` had ended after the
  discovery step (its process died at 05:10Z); the C2 step began only when I
  relaunched the runner at 05:15Z. Check `ops/state/*.pid` with `ps -p`, never
  infer a run from a log line that precedes it.

  sha256 of `event_study.py`; a comment edit after the stamp made them differ.
  Stamp last, after every edit to 30, event_study, freeze_guard, config, bheard.

  wrote to `ops/docs/…`. The shim now sets `PYTHONPATH` instead; LOCAL_SETUP says so.

  (`confirmatory_reading_dryrun_synthetic.csv`); harmless (34 --synthetic

  spec-audit tokens were satisfied by a second occurrence of the same text.
  Tokens now name the exact line. Always run the defeat attempt.

## 6. Conventions that are not obvious

- Every long job runs through a runner in `ops/` with a PID file and a state
  file under `ops/state/` (gitignored); poll by PID, never `pgrep -f`.
- Every change passes the gate twice; every new check gets a defeat attempt; the
  baseline is refreshed in the commit that adds the check (`--baseline` rewrites
  it from a clean run).
- Register CSVs are CRLF and are written through the csv module, never by hand;
  never edit them while a cold pass runs (its check stages rewrite them).
- `PYTHONHASHSEED=0` and single-threaded BLAS for anything whose bytes matter;
  the runners export them.
- The capsule (`docs/CONTEXT_CAPSULE.md`), the graph export
  (`docs/graph/graph_memory.jsonl`) and `vault/` are updated with every commit
  that changes state; the Mac copies are reconciled by import.
